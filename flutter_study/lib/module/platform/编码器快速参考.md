# creationParamsCodec 快速参考

## 一句话总结

`creationParamsCodec` 是用于在 Flutter 和原生平台之间**序列化/反序列化数据**的编码器。

---

## 核心概念

```
Flutter (Dart)  →  [编码器]  →  字节流  →  [解码器]  →  iOS (Swift/ObjC)
   Map               编码        传输        解码        NSDictionary
```

---

## 常用编码器对照表

| Flutter 端 | iOS 端 | 支持的数据类型 |
|-----------|--------|--------------|
| `StandardMessageCodec()` | `FlutterStandardMessageCodec.sharedInstance()` | null, bool, int, double, String, List, Map, TypedData |
| `JSONMessageCodec()` | `FlutterJSONMessageCodec.sharedInstance()` | JSON 基础类型 |
| `BinaryCodec()` | `FlutterBinaryCodec.sharedInstance()` | Uint8List（原始字节） |
| `StringCodec()` | `FlutterStringCodec.sharedInstance()` | String |

---

## 最简使用示例

### Flutter 端

```dart
UiKitView(
  viewType: 'my_view',
  creationParams: {'title': 'Hello', 'count': 42},
  creationParamsCodec: const StandardMessageCodec(), // ← 这里
)
```

### iOS 端

```swift
class MyViewFactory: NSObject, FlutterPlatformViewFactory {
    
    func create(..., arguments args: Any?) -> FlutterPlatformView {
        if let params = args as? [String: Any] {
            let title = params["title"] as? String
            let count = params["count"] as? Int
            print("收到：\(title), \(count)")
        }
        return MyView(...)
    }
    
    func createArgsCodec() -> FlutterMessageCodec & NSObjectProtocol {
        return FlutterStandardMessageCodec.sharedInstance() // ← 必须匹配
    }
}
```

## StandardMessageCodec 数据类型映射

| Dart | Swift/Objective-C | 示例 |
|------|-------------------|------|
| `null` | `nil` / `NSNull` | `"key": null` → `params["key"] is NSNull` |
| `bool` | `NSNumber` (Bool) | `true` → `as? Bool` |
| `int` | `NSNumber` (Int) | `42` → `as? Int` |
| `double` | `NSNumber` (Double) | `3.14` → `as? Double` |
| `String` | `NSString` / `String` | `"text"` → `as? String` |
| `List<T>` | `NSArray` / `[Any]` | `[1, 2, 3]` → `as? [Int]` |
| `Map<K, V>` | `NSDictionary` / `[K: V]` | `{"key": "val"}` → `as? [String: Any]` |
| `Uint8List` | `FlutterStandardTypedData` | 字节数据 |

## 常见错误

### ❌ 错误 1：编码器不匹配

```dart
// Flutter
creationParamsCodec: const StandardMessageCodec()
```

```swift
// iOS
func createArgsCodec() -> FlutterMessageCodec & NSObjectProtocol {
    return FlutterJSONMessageCodec.sharedInstance() // ❌ 不匹配！
}
```

**后果**：数据解析失败，可能崩溃

---

### ❌ 错误 2：强制类型转换

```swift
let title = params["title"] as! String // ❌ 如果类型不对会崩溃
```

**正确做法**：
```swift
let title = params["title"] as? String ?? "默认值" // ✅ 安全
```

---

### ❌ 错误 3：忽略 null 值

```swift
if let value = params["key"] {
    // value 可能是 NSNull！
    let str = value as? String // ❌ 如果是 NSNull，转换失败
}
```

**正确做法**：
```swift
if let value = params["key"], !(value is NSNull) {
    let str = value as? String
}
```

print('📤 发送参数: $creationParams');

print("📥 收到参数类型: \(type(of: args))")

if let dict = args as? [String: Any] {

    }
}

## 推荐做法

✅ **使用 StandardMessageCodec**（99% 场景够用）  
✅ **安全的类型转换**（使用 `as?` 和默认值）  
✅ **验证必需参数**（检查 nil 和类型）  
✅ **清晰的参数文档**（注释说明参数结构）  
✅ **打印调试信息**（开发时输出参数内容）

---

## 完整工作流程

```
1. Flutter 创建 creationParams
   ↓
2. creationParamsCodec 编码为字节流
   ↓
3. 通过 Platform Channel 发送
   ↓
4. iOS createArgsCodec() 解码
   ↓
5. 在 create(..., arguments:) 接收
   ↓
6. 类型转换并使用
```
