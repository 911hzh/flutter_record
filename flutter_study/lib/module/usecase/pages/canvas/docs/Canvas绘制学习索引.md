## 💻 代码文件

### 主Demo文件
📁 **[lib/module/usecase/pages/canvas/CancasPage.dart](../CancasPage.dart)**

**包含内容**：
- `CanvasPage` - 主页面（4个选项卡切换）
- `BasicShapesPainter` - 基础图形示例
- `PathPainter` - 路径绘制示例
- `TextAndGradientPainter` - 文字和渐变示例
- `AnimatedPainter` - 动画绘制示例

**运行方式**：
```dart
Navigator.push(
  context,
  MaterialPageRoute(builder: (context) => CanvasPage()),
);
```

---

### 实用案例文件
📁 **[lib/module/usecase/pages/canvas/PracticalExamples.dart](../PracticalExamples.dart)**

**包含内容**：
- `CircularProgressPainter` - 圆形进度条
- `LineChartPainter` - 折线图
- `GaugePainter` - 仪表盘
- `RipplePainter` - 水波纹
- `SignaturePainter` - 签名板
- `RadarChartPainter` - 雷达图

**使用方式**：
```dart
// 导入文件
import 'package:flutter_study/testPage/canvas/PracticalExamples.dart';

// 直接使用
CustomPaint(
  size: Size(200, 200),
  painter: CircularProgressPainter(progress: 0.75),
)
```

## ❓ 常见问题

### Q1: 应该先学哪个文档？
**A**: 如果是完全零基础，建议先看《自定义绘制完全指南》前三章，理解基本概念后再运行Demo。如果有一定基础，可以直接运行Demo，遇到不懂的地方再查阅指南。

### Q2: 代码可以直接用在项目里吗？
**A**: 可以！所有案例代码都是完整可用的，复制到项目中即可使用。根据实际需求调整参数和样式。

### Q3: 如何调试Canvas绘制代码？
**A**: 
1. 使用 `print()` 打印关键变量（如坐标、尺寸）
2. 先用简单的形状测试坐标是否正确
3. 使用不同颜色区分不同部分
4. Flutter DevTools 可以查看绘制性能

### Q4: 性能问题怎么办？
**A**: 参考《自定义绘制完全指南》第六章，重点关注：
- 复用Paint对象
- 合理使用shouldRepaint
- 避免在paint中创建临时对象
- 缓存复杂计算结果

### Q5: 如何实现触摸交互？
**A**: 使用 GestureDetector 包裹 CustomPaint，并重写 CustomPainter 的 `hitTest()` 方法。详见《自定义绘制完全指南》8.2节。
