# Flutter 四种编码器详细对比

## 总览对比表

| 编码器 | 支持数据类型 | 编码格式 | 性能 | 使用场景 | 复杂度 |
|-------|-----------|---------|-----|---------|-------|
| **StandardMessageCodec** | 最丰富 | 二进制 | 最高 | 通用场景（推荐） | 支持嵌套、类型化数组 |
| **JSONMessageCodec** | 基础类型 | JSON 文本 | 中等 | JSON 互操作 | 仅支持 JSON 兼容类型 |
| **BinaryCodec** | 仅字节数组 | 原始字节 | 最快 | 传输二进制数据 | 无序列化开销 |
| **StringCodec** | 仅字符串 | UTF-8 文本 | 高 | 传输文本 | 最简单 |

---

## 1. StandardMessageCodec（标准消息编码器）⭐ 推荐

### 📋 支持的数据类型（最全面）

```dart
// Dart 类型 → iOS 类型 → Android 类型

null           → nil/NSNull          → null
bool           → NSNumber(Bool)      → java.lang.Boolean
int            → NSNumber(Int/Long)  → Integer/Long
double         → NSNumber(Double)    → java.lang.Double
String         → NSString            → java.lang.String

// 类型化数组（特有）
Uint8List      → FlutterStandardTypedData → byte[]
Int32List      → FlutterStandardTypedData → int[]
Int64List      → FlutterStandardTypedData → long[]
Float32List    → FlutterStandardTypedData → float[]
Float64List    → FlutterStandardTypedData → double[]

// 集合类型
List<dynamic>  → NSArray             → java.util.ArrayList
Map<K, V>      → NSDictionary        → java.util.HashMap
```

### 💡 特点

- ✅ **支持嵌套结构**：List 中可以包含 Map，Map 中可以包含 List
- ✅ **支持类型化数组**：可以高效传输大量数值数据
- ✅ **二进制编码**：体积小、速度快
- ✅ **跨平台一致性**：Android 和 iOS 都完美支持
- ✅ **可扩展**：可以继承并添加自定义类型（128+ 类型标识符）

### 📝 使用示例

#### Flutter 端

```dart
import 'package:flutter/services.dart';

final params = {
  // 基础类型
  'name': 'Flutter',
  'count': 42,
  'price': 99.99,
  'enabled': true,
  'nullable': null,
  
  // 嵌套 Map
  'user': {
    'id': 1001,
    'email': 'user@example.com',
  },
  
  // List
  'tags': ['flutter', 'dart', 'mobile'],
  
  // 类型化数组（高效传输大量数据）
  'imageData': Uint8List.fromList([255, 128, 64, 32]),
  'coordinates': Float64List.fromList([1.0, 2.5, 3.7]),
};

UiKitView(
  viewType: 'my_view',
  creationParams: params,
  creationParamsCodec: const StandardMessageCodec(), // ← 这里
);
```

#### iOS 端

```swift
class MyViewFactory: NSObject, FlutterPlatformViewFactory {
    
    func create(..., arguments args: Any?) -> FlutterPlatformView {
        if let params = args as? [String: Any] {
            // 读取基础类型
            let name = params["name"] as? String
            let count = params["count"] as? Int
            let price = params["price"] as? Double
            let enabled = params["enabled"] as? Bool
            
            // 读取嵌套 Map
            if let user = params["user"] as? [String: Any] {
                let userId = user["id"] as? Int
                let email = user["email"] as? String
            }
            
            // 读取 List
            if let tags = params["tags"] as? [String] {
                print("Tags: \(tags)")
            }
            
            // 读取类型化数组
            if let imageData = params["imageData"] as? FlutterStandardTypedData {
                let bytes = imageData.data
                print("Image data: \(bytes.count) bytes")
            }
            
            if let coordinates = params["coordinates"] as? FlutterStandardTypedData {
                let data = coordinates.data
                // 转换为 Float64Array
                let count = data.count / MemoryLayout<Double>.size
                let array = data.withUnsafeBytes {
                    Array(UnsafeBufferPointer<Double>(
                        start: $0.baseAddress!.assumingMemoryBound(to: Double.self),
                        count: count
                    ))
                }
                print("Coordinates: \(array)")
            }
        }
        return MyView(...)
    }
    
    func createArgsCodec() -> FlutterMessageCodec & NSObjectProtocol {
        return FlutterStandardMessageCodec.sharedInstance()
    }
}
```

### 🔬 内部编码原理

StandardMessageCodec 使用**自定义二进制格式**：

```
每个值的编码：[类型字节][数据内容]

类型字节标识符：
0  = null
1  = true
2  = false
3  = 32位整数
4  = 64位整数
6  = 64位浮点数
7  = String (UTF-8)
8  = Uint8List
9  = Int32List
10 = Int64List
11 = Float64List
12 = List
13 = Map
14 = Float32List
128+ = 自定义类型（可扩展）
```

## 2. JSONMessageCodec（JSON 消息编码器）

### 📋 支持的数据类型（受限于 JSON）

```dart
// 仅支持 JSON 标准类型

null           → nil              → null
bool           → NSNumber(Bool)   → Boolean
num (int/double) → NSNumber       → Integer/Double
String         → NSString         → String
List           → NSArray          → ArrayList
Map<String, T> → NSDictionary     → HashMap
```

### ⚠️ 限制

- ❌ **不支持类型化数组**：Uint8List、Int32List 等会转换失败
- ❌ **Map 的 key 必须是 String**：不能使用数字或其他类型作为 key
- ❌ **数值精度限制**：int 超过 JavaScript 安全整数范围会损失精度
- ❌ **编码效率较低**：JSON 是文本格式，体积大于二进制

### 💡 特点

- ✅ **人类可读**：调试时可以看到 JSON 文本
- ✅ **跨语言兼容**：几乎所有语言都支持 JSON
- ✅ **Web 友好**：与 JavaScript 无缝对接

### 📝 使用示例

#### Flutter 端

```dart
import 'package:flutter/services.dart';

final params = {
  'name': 'Flutter',
  'version': 3.0,
  'features': ['hot-reload', 'cross-platform'],
  'config': {
    'theme': 'dark',
    'fontSize': 14,
  },
};

UiKitView(
  viewType: 'my_view',
  creationParams: params,
  creationParamsCodec: const JSONMessageCodec(), // ← JSON 编码
);

// ❌ 不支持：
// final params = {
//   'data': Uint8List.fromList([1, 2, 3]), // 会失败！
//   123: 'number key', // Map key 必须是 String
// };
```

#### iOS 端

```swift
class MyViewFactory: NSObject, FlutterPlatformViewFactory {
    
    func create(..., arguments args: Any?) -> FlutterPlatformView {
        // JSON 解码后与 StandardMessageCodec 类似
        if let params = args as? [String: Any] {
            let name = params["name"] as? String
            let version = params["version"] as? Double
            // ...
        }
        return MyView(...)
    }
    
    func createArgsCodec() -> FlutterMessageCodec & NSObjectProtocol {
        return FlutterJSONMessageCodec.sharedInstance() // ← JSON 解码
    }
}
```

### 🔬 内部编码原理

```dart
// Flutter 源码简化版
ByteData? encodeMessage(Object? message) {
  if (message == null) return null;
  
  // 1. 使用 dart:convert 将对象转为 JSON 字符串
  String jsonString = json.encode(message);
  // 例: {"name":"Flutter","count":42}
  
  // 2. 将 JSON 字符串转为 UTF-8 字节
  return StringCodec().encodeMessage(jsonString);
}
```

### 📊 性能对比

```
数据: {"name": "Flutter", "count": 42}

StandardMessageCodec:
  编码后大小: ~25 bytes (二进制)
  
JSONMessageCodec:
  编码后大小: ~32 bytes (JSON 文本)
  {"name":"Flutter","count":42}
```

## 3. BinaryCodec（二进制编码器）

### 📋 支持的数据类型

```dart
// 仅支持原始字节数据

Uint8List / ByteData  → NSData / FlutterStandardTypedData → java.nio.ByteBuffer
```

### 💡 特点

- ✅ **零开销**：不进行任何序列化，直接传递原始字节
- ✅ **最快速度**：没有编码/解码过程
- ✅ **适合二进制数据**：图片、音频、文件等

### ⚠️ 限制

- ❌ **只能传递字节**：无法传递结构化数据
- ❌ **需要自己处理数据格式**：原生端需要知道如何解析字节

### 📝 使用示例

#### Flutter 端

```dart
import 'dart:typed_data';
import 'package:flutter/services.dart';

// 读取图片文件
final imageBytes = await File('image.png').readAsBytes();

UiKitView(
  viewType: 'image_view',
  creationParams: imageBytes, // ← 直接传递 Uint8List
  creationParamsCodec: const BinaryCodec(),
);

// ❌ 不支持：
// final params = {'image': imageBytes}; // 不能传递 Map！
```

#### iOS 端

```swift
class ImageViewFactory: NSObject, FlutterPlatformViewFactory {
    
    func create(..., arguments args: Any?) -> FlutterPlatformView {
        // args 是原始的 NSData 或 FlutterStandardTypedData
        if let typedData = args as? FlutterStandardTypedData {
            let data = typedData.data
            // 直接使用字节数据
            let image = UIImage(data: data)
            print("Image size: \(data.count) bytes")
        }
        return ImageView(...)
    }
    
    func createArgsCodec() -> FlutterMessageCodec & NSObjectProtocol {
        return FlutterBinaryCodec.sharedInstance()
    }
}
```

### 🔬 内部编码原理

```dart
// Flutter 源码
class BinaryCodec implements MessageCodec<ByteData> {
  ByteData? decodeMessage(ByteData? message) => message; // 直接返回
  ByteData? encodeMessage(ByteData? message) => message; // 直接返回
}
```

完全没有编码过程！

## 4. StringCodec（字符串编码器）

### 📋 支持的数据类型

```dart
// 仅支持字符串

String  → NSString  → java.lang.String
```

### 💡 特点

- ✅ **简单直接**：只传递文本
- ✅ **UTF-8 编码**：支持所有 Unicode 字符
- ✅ **轻量高效**：比 JSON 更轻量

### ⚠️ 限制

- ❌ **只能传递字符串**：无法传递数字、Map、List 等

### 📝 使用示例

#### Flutter 端

```dart
import 'package:flutter/services.dart';

final welcomeMessage = "欢迎使用 Flutter 原生视图！🎉";

UiKitView(
  viewType: 'text_view',
  creationParams: welcomeMessage, // ← 直接传递 String
  creationParamsCodec: const StringCodec(),
);

// ❌ 不支持：
// final params = {'message': welcomeMessage}; // 不能传递 Map！
```

#### iOS 端

```swift
class TextViewFactory: NSObject, FlutterPlatformViewFactory {
    
    func create(..., arguments args: Any?) -> FlutterPlatformView {
        // args 直接是 String
        if let message = args as? String {
            print("收到消息: \(message)")
        }
        return TextView(message: args as? String ?? "")
    }
    
    func createArgsCodec() -> FlutterMessageCodec & NSObjectProtocol {
        return FlutterStringCodec.sharedInstance()
    }
}
```

### 🔬 内部编码原理

```dart
// Flutter 源码
class StringCodec implements MessageCodec<String> {
  ByteData? encodeMessage(String? message) {
    if (message == null) return null;
    // 将字符串转为 UTF-8 字节
    return ByteData.sublistView(utf8.encode(message));
  }
  
  String? decodeMessage(ByteData? message) {
    if (message == null) return null;
    // 将 UTF-8 字节转回字符串
    return utf8.decode(Uint8List.sublistView(message));
  }
}
```

## 详细对比场景

### 场景 1：传递复杂结构化数据

```dart
final params = {
  'user': {
    'id': 1001,
    'name': 'John',
    'scores': [95, 87, 92],
  },
  'metadata': {
    'timestamp': 1678901234,
    'device': 'iPhone 14',
  },
};
```

| 编码器 | 是否支持 | 建议 |
|-------|---------|------|
| StandardMessageCodec | ✅ 完美支持 | ⭐ 推荐使用 |
| JSONMessageCodec | ✅ 支持 | 可用，但体积大 |
| BinaryCodec | ❌ 不支持 | 需要自己序列化 |
| StringCodec | ❌ 不支持 | 需要先转 JSON 字符串 |

---

### 场景 2：传递图片数据

```dart
final imageBytes = await File('avatar.png').readAsBytes();
```

| 编码器 | 是否支持 | 建议 |
|-------|---------|------|
| StandardMessageCodec | ✅ 作为 Uint8List | 可用 |
| JSONMessageCodec | ❌ 不支持字节数组 | 不推荐 |
| BinaryCodec | ✅ 直接传递 | ⭐ 最佳选择 |
| StringCodec | ❌ 不支持 | Base64 可以但低效 |

---

### 场景 3：传递简单配置字符串

```dart
final config = "theme:dark;fontSize:16";
```

| 编码器 | 是否支持 | 建议 |
|-------|---------|------|
| StandardMessageCodec | ✅ 支持 | 可用但大材小用 |
| JSONMessageCodec | ✅ 支持 | 可用但大材小用 |
| BinaryCodec | ❌ 需要转字节 | 不推荐 |
| StringCodec | ✅ 完美支持 | ⭐ 最简洁 |

---

### 场景 4：传递数值数组（如坐标、传感器数据）

```dart
final coordinates = Float64List.fromList([
  120.123456, 30.654321,
  120.234567, 30.765432,
  // ...1000个坐标点
]);
```

| 编码器 | 是否支持 | 性能 | 建议 |
|-------|---------|------|------|
| StandardMessageCodec | ✅ Float64List | 最高 | ⭐ 最佳选择 |
| JSONMessageCodec | ⚠️ 转为 List | 低 | 数据量大时慢 |
| BinaryCodec | ✅ 直接传递 | 最高 | 需要手动解析 |
| StringCodec | ❌ 不适合 | 最低 | 不推荐 |

## 编码器选择决策树

```
开始
  ↓
需要传递结构化数据（Map/List）？
  ├─ 是 → 需要 TypedData（Uint8List、Float64List 等）？
  │       ├─ 是 → StandardMessageCodec ⭐
  │       └─ 否 → 需要 JSON 互操作或调试？
  │               ├─ 是 → JSONMessageCodec
  │               └─ 否 → StandardMessageCodec ⭐
  │
  └─ 否 → 只传递原始字节（图片、文件）？
          ├─ 是 → BinaryCodec ⭐
          └─ 否 → 只传递字符串？
                  ├─ 是 → StringCodec ⭐
                  └─ 否 → StandardMessageCodec ⭐
```

## 最佳实践建议

### ✅ 推荐

1. **默认使用 StandardMessageCodec**
   - 99% 的场景都适用
   - 性能、功能、兼容性最佳平衡

2. **传递大文件用 BinaryCodec**
   - 图片、音频、视频等二进制文件
   - 或者更好的方案：传递文件路径而不是文件内容

3. **简单文本用 StringCodec**
   - 只需要传递一个字符串时
   - 比 StandardMessageCodec 更语义化

4. **需要 JSON 互操作时用 JSONMessageCodec**
   - 与 Web 端通信
   - 需要人类可读的调试信息

### ❌ 避免

1. **不要用 JSONMessageCodec 传递大数据**
   - JSON 编码体积大、速度慢
   - 不支持高效的类型化数组

2. **不要用 BinaryCodec 传递结构化数据**
   - 需要自己处理序列化，容易出错
   - StandardMessageCodec 已经很高效

3. **不要混用编码器**
   - Flutter 端和原生端必须完全匹配
   - 否则会导致解析失败或崩溃

## 总结

| 使用场景 | 推荐编码器 |
|---------|-----------|
| 🏆 **通用场景（默认选择）** | **StandardMessageCodec** |
| 📦 复杂结构化数据 | StandardMessageCodec |
| 🔢 大量数值数据 | StandardMessageCodec (TypedData) |
| 🖼️ 二进制文件（图片、音频） | BinaryCodec 或传递文件路径 |
| 📝 简单文本消息 | StringCodec |
| 🌐 JSON 互操作 | JSONMessageCodec |
| 🐛 调试需要可读格式 | JSONMessageCodec |

**简单记忆**：没有特殊需求时，永远使用 `StandardMessageCodec`！
