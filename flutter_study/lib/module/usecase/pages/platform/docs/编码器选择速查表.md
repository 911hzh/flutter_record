需要传递什么数据？

## 核心特性对比

### 1️⃣ StandardMessageCodec —— 全能王 👑

```dart
✅ 支持类型最多
✅ 性能最好
✅ 二进制编码（体积小）
✅ 支持嵌套结构
✅ 支持类型化数组

❌ 无明显缺点
```

**适用率：95%** 的场景

---

### 2️⃣ JSONMessageCodec —— 人类友好型

```dart
✅ JSON 格式（可读）
✅ 跨语言兼容
✅ Web 友好

❌ 不支持 Uint8List 等
❌ Map key 必须是 String
❌ 体积大、速度慢
```

**适用率：3%** 的场景（需要 JSON 互操作）

---

### 3️⃣ BinaryCodec —— 速度狂魔

```dart
✅ 零序列化开销
✅ 最快速度
✅ 适合二进制文件

❌ 只支持字节
❌ 无法传递结构化数据
```

**适用率：1%** 的场景（传递二进制文件）

---

### 4️⃣ StringCodec —— 极简主义

```dart
✅ 最简单
✅ UTF-8 支持
✅ 轻量高效

❌ 只支持字符串
```

**适用率：1%** 的场景（只传递文本）

## 实际场景示例

### ✅ 场景 1：用户信息

```dart
// 数据
final params = {
  'userId': 1001,
  'name': 'John',
  'email': 'john@example.com',
  'isPremium': true,
};

// 选择
creationParamsCodec: const StandardMessageCodec() ⭐
```

---

### ✅ 场景 2：地图坐标（大量数值）

```dart
// 数据
final params = {
  'coordinates': Float64List.fromList([
    120.123, 30.456, 120.789, 30.012, ...
  ]),
};

// 选择
creationParamsCodec: const StandardMessageCodec() ⭐
// 原因：高效传输 TypedData
```

---

### ✅ 场景 3：头像图片

```dart
// 方案 A：传递字节（不推荐，数据量大）
final params = await File('avatar.png').readAsBytes();
creationParamsCodec: const BinaryCodec()

// 方案 B：传递路径（推荐）⭐
final params = {'avatarPath': '/path/to/avatar.png'};
creationParamsCodec: const StandardMessageCodec()
```

---

### ✅ 场景 4：配置字符串

```dart
// 数据
final params = "theme=dark&fontSize=16";

// 选择
creationParamsCodec: const StringCodec() ⭐
```

---

### ✅ 场景 5：与 Web 通信

```dart
// 数据
final params = {
  'action': 'login',
  'credentials': {'user': 'john', 'pass': '***'},
};

// 选择
creationParamsCodec: const JSONMessageCodec() ⭐
// 原因：Web 端需要 JSON 格式
```

## 常见错误示例

### ❌ 错误 1：用 JSON 传递字节数组

```dart
// ❌ 错误
final params = {
  'imageData': Uint8List.fromList([255, 128, 64]),
};
creationParamsCodec: const JSONMessageCodec() // 会失败！

// ✅ 正确
creationParamsCodec: const StandardMessageCodec()
```

---

### ❌ 错误 2：用 Binary 传递结构化数据

```dart
// ❌ 错误（需要自己序列化）
final params = {'name': 'John', 'age': 30};
creationParamsCodec: const BinaryCodec() // 不支持！

// ✅ 正确
creationParamsCodec: const StandardMessageCodec()
```

---

### ❌ 错误 3：用 String 传递对象

```dart
// ❌ 错误（需要自己转 JSON）
final params = {'name': 'John'};
creationParamsCodec: const StringCodec() // 不支持！

// ✅ 正确
creationParamsCodec: const StandardMessageCodec()
```

---

### ❌ 错误 4：编码器不匹配

```dart
// Flutter 端
creationParamsCodec: const StandardMessageCodec()

// iOS 端
func createArgsCodec() -> FlutterMessageCodec & NSObjectProtocol {
    return FlutterJSONMessageCodec.sharedInstance() // ❌ 不匹配！
}

// ✅ 正确：必须使用相同编码器
func createArgsCodec() -> FlutterMessageCodec & NSObjectProtocol {
    return FlutterStandardMessageCodec.sharedInstance()
}
```

## 最终建议 💡

### 🏆 黄金法则

> **当你不确定用哪个时，永远选择 `StandardMessageCodec`！**

它是：
- ✅ 性能最好的
- ✅ 功能最全的
- ✅ 兼容性最好的
- ✅ Flutter 官方推荐的

### 📝 记忆口诀

```
Standard 最全能，默认就用它 👑
JSON 人类读，互操作友好 📄
Binary 传字节，图片文件好 🖼️
String 最简单，纯文本就行 ✏️
```

## 代码模板

### 模板 1：StandardMessageCodec（推荐）

```dart
// Flutter 端
UiKitView(
  viewType: 'my_view',
  creationParams: {
    'config': {...},
    'data': [...],
  },
  creationParamsCodec: const StandardMessageCodec(),
)

// iOS 端
func createArgsCodec() -> FlutterMessageCodec & NSObjectProtocol {
    return FlutterStandardMessageCodec.sharedInstance()
}
```

### 模板 2：BinaryCodec（二进制文件）

```dart
// Flutter 端
final bytes = await File('data.bin').readAsBytes();
UiKitView(
  viewType: 'my_view',
  creationParams: bytes,
  creationParamsCodec: const BinaryCodec(),
)

// iOS 端
func createArgsCodec() -> FlutterMessageCodec & NSObjectProtocol {
    return FlutterBinaryCodec.sharedInstance()
}
```

### 模板 3：StringCodec（纯文本）

```dart
// Flutter 端
UiKitView(
  viewType: 'my_view',
  creationParams: "Hello Native!",
  creationParamsCodec: const StringCodec(),
)

// iOS 端
func createArgsCodec() -> FlutterMessageCodec & NSObjectProtocol {
    return FlutterStringCodec.sharedInstance()
}
```

### 模板 4：JSONMessageCodec（JSON 互操作）

```dart
// Flutter 端
UiKitView(
  viewType: 'my_view',
  creationParams: {'key': 'value'},
  creationParamsCodec: const JSONMessageCodec(),
)

// iOS 端
func createArgsCodec() -> FlutterMessageCodec & NSObjectProtocol {
    return FlutterJSONMessageCodec.sharedInstance()
}
```
