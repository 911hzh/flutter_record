# 动画与页面转场

首页「动画与页面转场」进入 `/animate`，使用 SlideTransition 观察页面向上进入与返回效果。

- [AnimatePage.dart](AnimatePage.dart) 是入口页面。
- [AnimateSeconedPage.dart](AnimateSeconedPage.dart) 展示后续页面和下拉返回。
- [AnimateDownPage.dart](AnimateDownPage.dart) 保存原有的转场实验代码。

验证时进入子页，观察进入动画及返回效果。重绘隔离实验见 [RepaintBoundary](../repaintboundary/README.md)。

页面使用主题卡片和明确的操作按钮。依次点击「体验向上转场」「打开下拉返回页」，观察转场和下拉效果。
