# Flutter 渐变文字使用指南

## 📝 简介

渐变文字是一种炫酷的文字效果，可以让文字显示多种颜色的渐变。本指南提供了完整的实现方案和使用方法。

## 🎯 效果预览

在应用中已经实现了以下4种渐变文字效果：

1. **线性渐变文字** - 紫色→蓝色→粉色
2. **彩虹色效果** - 红→橙→黄→绿→蓝→紫
3. **金色渐变** - 高级的金色光泽效果
4. **多行渐变文字** - 支持多行文字的渐变

## 🚀 快速使用

### 方法一：使用 GradientText 组件（推荐）

这是最简单的使用方式：

```dart
GradientText(
  text: '渐变文字',
  style: TextStyle(
    fontSize: 32,
    fontWeight: FontWeight.bold,
  ),
  gradient: LinearGradient(
    colors: [Colors.purple, Colors.blue, Colors.pink],
  ),
)
```

### 方法二：使用 CustomPaint

如果需要更灵活的控制：

```dart
CustomPaint(
  size: Size(200, 50),  // 指定大小
  painter: GradientTextPainter(
    text: '渐变文字',
    textStyle: TextStyle(fontSize: 32),
    gradient: LinearGradient(
      colors: [Colors.red, Colors.orange],
    ),
  ),
)
```

```dart
        colors: [Colors.yellow, Colors.orange],
      ),
    ),
  ],

```

### 3. 动画渐变文字

结合 AnimationController 实现动态渐变：

```dart
class AnimatedGradientText extends HookWidget {
  final String text;

  const AnimatedGradientText({required this.text});

  @override
  Widget build(BuildContext context) {
    final controller = useAnimationController(
      duration: Duration(seconds: 3),
    )..repeat(reverse: true);

    return AnimatedBuilder(
      animation: controller,
      builder: (context, child) {
        return GradientText(
          text: text,
          style: TextStyle(fontSize: 32, fontWeight: FontWeight.bold),
          gradient: LinearGradient(
            colors: [
              Color.lerp(Colors.red, Colors.blue, controller.value)!,
              Color.lerp(Colors.blue, Colors.purple, controller.value)!,
              Color.lerp(Colors.purple, Colors.red, controller.value)!,
            ],
          ),
        );
      },
    );
  }
}
```

## 🔧 源码解析

### GradientTextPainter 类

```dart
class GradientTextPainter extends CustomPainter {
  final String text;
  final TextStyle textStyle;
  final Gradient gradient;

  @override
  void paint(Canvas canvas, Size size) {
    // 1. 创建 TextPainter
    final textPainter = TextPainter(
      text: TextSpan(text: text, style: textStyle),
      textDirection: TextDirection.ltr,
    )..layout();

    // 2. 计算居中位置
    final offset = Offset(
      (size.width - textPainter.width) / 2,
      (size.height - textPainter.height) / 2,
    );

    // 3. 创建渐变 shader
    final rect = Rect.fromLTWH(
      offset.dx,
      offset.dy,
      textPainter.width,
      textPainter.height,
    );
    final shader = gradient.createShader(rect);

    // 4. 应用 shader 到文字
    final paint = Paint()..shader = shader;
    final gradientTextSpan = TextSpan(
      text: text,
      style: textStyle.copyWith(foreground: paint),
    );
    
    // 5. 绘制带渐变的文字
    final gradientTextPainter = TextPainter(
      text: gradientTextSpan,
      textDirection: TextDirection.ltr,
    )..layout();
    
    gradientTextPainter.paint(canvas, offset);
  }
}
```

### 核心技术点

1. **TextStyle.foreground**: 使用 foreground 属性而不是 color，这样才能应用自定义的 Paint
2. **Shader**: 通过 gradient.createShader() 创建着色器
3. **TextPainter**: Flutter 官方推荐的文字绘制方式

## ⚠️ 注意事项

### 1. 性能考虑
- 渐变文字需要额外的绘制计算，不建议在列表中大量使用
- 如果需要在列表中使用，考虑缓存 TextPainter

### 2. 文字大小
- 确保 CustomPaint 的 size 足够容纳文字
- 可以先用 TextPainter.layout() 计算文字尺寸

### 3. 兼容性
- 所有平台都支持
- iOS、Android、Web、Desktop 都可以正常显示
