## 📝 命名规范说明

### 为什么使用大驼峰？

虽然 Dart 官方建议库文件使用**小写下划线**命名（snake_case），但在某些情况下使用**大驼峰**（PascalCase）也有其优势：

#### ✅ 使用大驼峰的优势

1. **文件名与类名一致**
   ```
   CircularProgressPainter.dart  →  class CircularProgressPainter
   ```
   一目了然，易于理解

2. **快速定位**
   在 IDE 中搜索类名时，文件名会立即出现

3. **组件化开发**
   每个文件包含一个主要的类，文件名即类名

4. **团队习惯**
   某些团队或项目采用这种命名风格

#### ⚠️ Dart 官方推荐

Dart 官方文档推荐使用 **snake_case**：
```
circular_progress_painter.dart  ✓ (官方推荐)
CircularProgressPainter.dart    ✓ (也可接受)
```

两种方式都是合法的，选择哪种取决于：
- 团队规范
- 项目风格
- 个人喜好
